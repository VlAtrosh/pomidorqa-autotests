# Матрица покрытия требований PomidorQA

Покрытие считается от [спецификации](./requirements.md) — 50 функциональных требований MVP.

**Итого: 29 automated + 6 partial + 1 out of scope + 14 не покрыто = 50**

**Покрытие: 29 из 50 — 58%.**

## Легенда

| Статус | Что значит |
|--------|------------|
| `automated` | Тест упадёт, если поведение сломается |
| `partial` | Покрыта наблюдаемая часть, серверная — нет |
| `known defect` | Продукт требование не выполняет, тест помечен `test.fail()` |
| `out of scope` | Состояние через интерфейс недостижимо (black-box) |
| `не покрыто` | Требование есть, теста пока нет |
